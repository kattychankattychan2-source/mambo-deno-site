# 🐴 Mambo Site

An interactive website featuring Mambo from Uma Musume!

## Features
- Click the "Just Click" button to see Mambo
- Mambo GIF appears with animation
- "Mambo!" text displays
- Mambo sound plays

## How to Use

1. Clone the repository
2. Add your Mambo GIF as `mambo.gif`
3. Add your Mambo sound file as `mambo-sound.mp3`
4. Open `index.html` in your browser

## Files Needed
- `mambo.gif` - The Mambo animation/GIF
- `mambo-sound.mp3` - The Mambo sound effect

## Deployment

To deploy on Deno Deploy (mambo.deno.dev):

1. Create a `deno.json` file
2. Set up a simple Deno server to serve the static files
3. Deploy to Deno
